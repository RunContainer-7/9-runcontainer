# Setup problems

Problems getting RunContainer itself installed or opened.

## I can't find an official download

The official download is the installer on the [Downloads](/downloads) page. Don't use copies from unofficial sources.

## Windows warns me about the file

Windows may warn about files downloaded from the internet. Only continue if the file came from a link on the official [Downloads](/downloads) page. If you're unsure, don't run it.

## RunContainer won't open

- Restart your PC and try again.
- Check that your PC meets the [prerequisites](/getting-started/prerequisites). Detailed requirements will be published with the first release.
- On a managed work or school device, policies may block it. Ask your administrator.

## My security software blocks it

Security software may react to tools that manage other applications. **Don't disable your security software** to work around this. Report the problem instead, so it can be investigated. See [Reporting security issues](/reference/security) if you think something is genuinely wrong.
