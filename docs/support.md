# Support

RunContainer is **free and open source**. Support comes from the community.

If you enjoy RunContainer, you can support the project by [giving RunContainer a star on GitHub](https://github.com/RunContainer-7/runcontainer).

## Before you ask

1. Read the [Troubleshooting](/troubleshooting/) pages. Many common problems are covered there.
2. Check the [Known limitations](/reference/limitations) and the [FAQ](/reference/faq).
3. Search the [issue tracker](https://github.com/RunContainer-7/runcontainer/issues) to see whether your problem has already been reported.

## What to include

- The version of RunContainer you're using, and the Windows version.
- What you did, what you expected, and what happened instead.
- Any error message, copied as text where possible.

Remove usernames, licence keys and other personal details before sharing screenshots or logs.

## Bugs and feature requests

Use the [issue tracker](https://github.com/RunContainer-7/runcontainer/issues) for bugs and feature requests. The [Contribution guide](/reference/contributing) explains what makes a good report.

You can also join the Discord server to talk through a bug or feature idea before you file it. Join the [Discord server](https://discord.gg/UKTGRMMmC4) and see the [Contribution guide](/reference/contributing) for what to include in a report.

## Security issues

Please don't report vulnerabilities in public channels. See [Reporting security issues](/reference/security).
