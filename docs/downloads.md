# Downloads

RunContainer is **free and open source**. Its source code is at [github.com/RunContainer-7/runcontainer](https://github.com/RunContainer-7/runcontainer). No official installer has been released yet.

<div class="rc-dl-status">
  <span class="rc-badge rc-badge--none">Unavailable</span>
  <p><strong>There's no official public release of RunContainer yet.</strong> No installer, preview build or checksum has been published.</p>
</div>

::: danger Beware of unofficial downloads
Any file presented as a RunContainer installer that isn't linked from this page is **not official**. Don't run it.
:::
