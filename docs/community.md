## Source code

RunContainer is **free and open source**. The source code is public at [github.com/RunContainer-7/runcontainer](https://github.com/RunContainer-7/runcontainer). You can read it, build it yourself, and contribute to it. See [Installation](/getting-started/installation#building-from-source) for build steps.

## Support

Need help with RunContainer? See the [Support page](/support) for the Discord server and tips on asking for help.

## Issues and feature requests

Bug reports and feature requests go to the [issue tracker](https://github.com/RunContainer-7/runcontainer/issues). The [Contribution guide](/reference/contributing) explains what makes a good report.

You can also join the community on Discord to talk through an idea or a bug before you file it. See the [Support page](/support).

## Security

Please don't report vulnerabilities publicly. See [Reporting security issues](/reference/security).
