## Source code

RunContainer is **free and open source**. The source code is public at [github.com/north-star-info/runcontainer](https://github.com/north-star-info/runcontainer). You can read it, build it yourself, and contribute to it. See [Installation](/getting-started/installation#building-from-source) for build steps.

## Support

Need help with RunContainer? See the [Support page](/support) for the Discord server and tips on asking for help.

## Issues and feature requests

Bug reports and feature requests go to the [issue tracker](https://github.com/north-star-info/runcontainer/issues). The [Contribution guide](/reference/contributing) explains what makes a good report.

## Security

Please don't report vulnerabilities publicly. See [Reporting security issues](/reference/security).
