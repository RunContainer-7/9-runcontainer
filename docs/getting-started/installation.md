# Installation

::: warning No official release yet
RunContainer doesn't have an official public release or installer yet. **Don't download RunContainer from unofficial websites or file-sharing services**: files claiming to be RunContainer that aren't linked from the [Downloads](/downloads) page aren't official.
:::

## When a release is available

Installation instructions will appear here once an official release is published. They'll cover:

1. Where to download the official release, which will be linked from [Downloads](/downloads).
2. How to verify that the file you downloaded is genuine.
3. How to install and launch RunContainer for the first time.

## Building from source

RunContainer is free and open source. The source is at [github.com/north-star-info/runcontainer](https://github.com/north-star-info/runcontainer). The repository's README gives these steps (RunContainer is a Windows application):

1. Clone the repository: `git clone https://github.com/north-star-info/runcontainer.git`
2. Open the folder and install dependencies: `npm install`
3. Start the app: `npm start`

The repository's package.json also includes a Windows installer build (`npm run dist`). Build steps come from the repository, not from an official release, so check its README for the latest instructions.
