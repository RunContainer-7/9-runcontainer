# Quick start

Everything needed to go from a download to a running app, and to the iPhone companion. Each step links to the page that explains it in more detail.

## 1. Install RunContainer

1. Open [Downloads](/downloads) and get the **Stable** installer.
2. Run it and follow the wizard. Windows may warn you: Stable is self-signed, and Nightly is unsigned. See [Installation](/getting-started/installation) for the checksum and the warning.
3. Open RunContainer from the desktop shortcut.

You do not need to prepare anything first. RunContainer creates what each app needs when you install it.

## 2. Run your first app

1. On the **Apps** tab, press **+**, then **Install EXE**.
2. Pick the installer. RunContainer validates it, creates the app's environment, and runs its setup inside RunContainer.
3. When setup finishes, the app appears in **My Apps**. Press **Run**.
4. The app opens in a RunContainer window. Press **Close** when you are done; the app stays installed.

More: [Installing applications](/user-guide/applications) and [Running & stopping](/user-guide/running).

## 3. Use an app from an iPhone (optional)

1. In RunContainer, open **Settings → iPhone companion** and press **Turn on**.
2. Press **Copy address**, send it to the iPhone, and open it in **Safari**.
3. Tap **Share → Add to Home Screen**.
4. Open the companion and enter the six-digit code shown on the PC.

The full guide, including Tailscale for when you are away from home, is on the [iPhone companion](/user-guide/companion) page.

## Where everything is

| Tab | What it is for |
| --- | --- |
| **Sources** | Import an app from a URL, or pick a local EXE. |
| **Apps** | Everything you have added: run, close, reset and remove. |
| **Tweaks** | Per-app launch arguments and limits, plus the JIT launcher. |
| **Settings** | Appearance, how installers run, and the iPhone companion. |
| **Profiles** | How much access each app gets: default, relaxed or locked. |
| **Info** | What the app does, in plain language. |
| **Updates** | New versions of RunContainer itself. |
