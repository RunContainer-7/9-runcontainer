# Contribution guide

Thanks for your interest in improving RunContainer. Bug reports, compatibility notes and documentation fixes are all valuable.

::: info Where to contribute
RunContainer is free and open source. The [source repository](https://github.com/north-star-info/runcontainer) and [issue tracker](https://github.com/north-star-info/runcontainer/issues) are public. For questions, see the [Support page](/support). Please don't rely on unofficial channels claiming to represent the project. All official links are on [Community & links](/community).
:::

## Ways to contribute

- **Report bugs**, such as something that doesn't work as described here.
- **Report compatibility**, letting others know which applications work or don't.
- **Suggest features** that would make RunContainer more useful.
- **Improve the documentation** by fixing mistakes, unclear wording or missing steps.

## Reporting bugs

A useful bug report includes:

1. **What you did:** the steps, in order.
2. **What you expected** to happen.
3. **What actually happened,** including the exact error message.
4. **Your setup:** your Windows version and the RunContainer version.
5. **Whether it happens every time**, and whether it happens in a fresh environment.

::: warning Remove personal information
Before posting, remove usernames, email addresses, file paths containing your name, licence keys and anything else private. See [Privacy & credentials](/safety/privacy#sharing-logs-and-screenshots).
:::

**Security vulnerabilities shouldn't be reported publicly.** See [Reporting security issues](/reference/security).

## Reporting compatibility

When reporting how an application behaves in RunContainer, include:

- the application's **name and version**,
- **where you got it** (for example, the official website),
- **what works and what doesn't**,
- whether its installer asked for **drivers, services or a restart**.

## Suggesting features

Describe **the problem you're trying to solve**, not just the solution. This makes it easier to find the best approach.

## Improving this website

This website is built with [VitePress](https://vitepress.dev/) from Markdown files. Once the website source is public, each documentation page will have a "Suggest a change to this page" link.

Writing guidelines:

- Describe what **users see and do**, not how RunContainer works internally.
- Don't promise safety, malware protection or universal compatibility.
- Mark anything unconfirmed as unconfirmed, rather than guessing.
- Keep language plain and friendly.

## Code of conduct

Be respectful and constructive. Assume good intent, and help keep the project welcoming to newcomers.
